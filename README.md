Krórkie readme:

1. Wygeneruj klucz API na stronie https://aistudio.google.com/ 
2. Stwórz foldery na swoim google drive: Wejście, Wyjście, Archiwum
3. Stwórz projekt na https://script.google.com/ będąc zalogowany na tym samym koncie co stworzyłeś foldery i wygenerowałeś klucz
4. Wklej main.js do stworzonego projektu
5. Zamien ID folderów oraz klucz API na swój własny
6. Wejdź do zakładki Triggers (Wyzwalacze) i dodaj nowy wyzwalacz funkcji processDriveImages
7. Zmień atrybuty na Select event source: Time-driven, Select type of time-based trigger: Minutes timer, Select minute interval: Every minute i zapisz
8. Wrzuć zdjęcie z równaniem do folderu Wejście i poczekaj minute na efekt w folderze Wyjście i Archiwum
